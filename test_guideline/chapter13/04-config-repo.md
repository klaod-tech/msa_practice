# 04. config-repo: resilience4j 설정

> 시작: 교수님 `Chapter12` 상태 / 결과: 교수님 `Chapter13`과 같은 코드(교재 영어 주석만 빠짐).
> 표기: `★ 추가` / `★ 변경 (전: ...)` / `★ 삭제` = 이전 장 대비 바뀌는 줄. md 화면에서 Ctrl+F로 `★`를 찾으면 바뀐 줄만 볼 수 있다.

`product-composite.yml`에 `resilience4j.*`(타임아웃, 재시도, 서킷 브레이커 값)와 health에 회로 상태 표시.
`spring.jackson.datatype.enum.write-enums-using-to-string: false`: Boot 4(Jackson 3)는 enum을 `toString()`으로 쓰는데, 서킷 브레이커 이벤트의 상태 전환이 `State transition from ...` 같은 문장으로 나오지 않게 이름(`CLOSED_TO_OPEN`)으로 쓰게 한다. test-em-all이 이 이름을 확인한다.
